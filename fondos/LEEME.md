# Mis fondos para Flow Launcher

Subí aquí tus imágenes (**.jpg, .png o .webp**) y aparecen en el launcher:

**Flow Launcher → Ajustes → Mis fondos de GitHub**

- Cada vez que tocás esa opción, el launcher descarga las imágenes nuevas y borra las que quitaste de esta carpeta.
- El nombre del archivo es el nombre que se ve en la TV (los `_` se muestran como espacios). Ej.: `noche_de_combate.jpg`.
- Lo ideal: imágenes horizontales de 1920×1080. Máximo 25 MB cada una.
- Subir imágenes aquí **no** genera un APK nuevo.

## Cómo subir desde el celular

1. Abrí esta carpeta en github.com (en el navegador, modo "sitio de escritorio" si no ves el botón).
2. Tocá **Add file → Upload files**.
3. Elegí las imágenes y tocá **Commit changes**.
